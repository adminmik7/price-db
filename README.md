# PriceDB

Настольное приложение (Windows, Tauri) с веб-интерфейсом для агрегации прайсов
поставщиков: импорт XLSX/CSV в SQLite, полнотекстовый поиск по товарам,
управление базой, планировщик автоматических импортов и Telegram-бот для
удалённого запуска задач.

## Возможности

- **Импорт прайсов** — загрузка XLSX/CSV, пресеты с маппингом колонок, выбор
  листов книги, автоматическое определение кодировки и строки заголовков.
- **Пакетная загрузка** — обработка нескольких файлов по одному пресету.
- **Поиск и управление товарами** — полнотекстовый поиск (SQLite FTS5) по
  названию и артикулу, фильтры по поставщикам, актуальность и цены.
- **Статистика** — по поставщикам и по последним задачам, сведения о базе
  данных (размер, индексы, vacuum).
- **Экспорт** — выгрузка данных в XLSX/CSV; в настольном приложении — нативный
  диалог «Сохранить как».
- **Планировщик** — задачи импорта по cron-расписанию, запуск вручную и
  пакетный запуск, импорт по ссылке и по email (IMAP), журналы запусков.
- **Telegram-бот** — запуск задач по ссылкам и письмам, статус базы, история
  импортов, поиск товара по артикулу, ежедневный дайджест.
- **Проверка обновлений** — при старте настольное приложение сверяет свою
  версию с последним релизом на GitHub и предлагает обновление.
- **Доступ** — авторизация с ролями `admin` и `user`; пароли хранятся только в
  виде scrypt-хэшей, сессии живут в памяти сервера.

## Технологии

| Компонент | Стек |
|---|---|
| Бэкенд | Node.js, Express, better-sqlite3, xlsx, node-cron, imapflow, multer |
| Фронтенд | Webix (SPA без сборщика), страницы в `public/`, скрипты в `js/` |
| Десктоп | Tauri 2 (Rust), WebView2 |
| Бот | Python 3, aiogram 3 |

## Структура проекта

```
server.js          — бэкенд: API, импорт, планировщик, авторизация (Express)
js/                — скрипты страниц фронтенда
public/            — HTML-страницы интерфейса
src-tauri/         — оболочка Tauri (Rust-команды: адрес сервера, экспорт,
                     проверка версии, открытие ссылок)
bot/               — Telegram-бот (Python)
db/                — базы SQLite: data.sqlite, presets.sqlite, schedule.sqlite
tools/             — утилиты сборки и проверки (make-dist, check-*)
dist/              — собранный фронтенд для встраивания в Tauri (генерируется)
vps/               — зеркало развёртывания на сервере (тот же бэкенд + exe)
imported/, uploads/— загруженные и импортированные файлы (генерируются)
```

## Запуск и сборка

```bash
npm install            # зависимости бэкенда
npm start              # сервер на порту 80 (node server.js)

npm run dev            # десктоп в режиме разработки (tauri dev)
npm run build          # сборка PriceDB.exe + копия в vps/
npm run build:frontend # только сборка dist/ (фронтенд)
npm run check          # проверка конфигурации бэкенда
```

Десктопное приложение подключается к бэкенду по адресу, который вводится на
экране входа (опционально запоминается в файле `server.txt` в каталоге
конфигурации приложения). В браузере фронтенд и API находятся на одном
origin — отдельная настройка не нужна.

### Telegram-бот

Запуск: `python bot/bot.py` (зависимости — `bot/requirements.txt`).
Настройка через переменные окружения: `BOT_TOKEN` (токен бота),
`BOT_SERVER_URL` (адрес бэкенда), дополнительно — `DB_PATH`,
`SCHEDULE_DB_PATH`, `DAILY_SUMMARY_HOUR`, `LOG_LEVEL` и другие (см.
`bot/config.py`). Секреты задаются только переменными окружения и локальными
файлами вне репозитория.

## Развёртывание

- **Настольно** — `npm run build`, готовый `PriceDB.exe` копируется в `vps/`.
- **На сервере** — каталог `vps/` содержит рабочую копию бэкенда, фронтенда и
  бота; запуск теми же командами (`npm start`), базы данных — в `vps/db/`.
